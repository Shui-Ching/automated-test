# [PUB-WEB-FN-001] 前台 前台頁面列表

## 1. 商業邏輯

| 項目 | 定義 |
| :--- | :--- |
| **需求描述** | 身為 前台瀏覽者，我想要 看到目前所有可瀏覽的頁面清單，以便於 選擇要閱讀的內容。 |
| **使用對象** | 前台瀏覽者 |
| **前提條件** | 無。本頁不需登入即可瀏覽。 |
| **基本流程** | 1. 瀏覽者開啟前台頁面列表。<br>2. 系統讀取後台所建立之全部頁面資料，依預設排序顯示。<br>3. 瀏覽者點擊任一筆之頁面名稱，系統導向 `[PUB-WEB-FN-002] 前台 頁面內容顯示` 並隨附主鍵資訊。 |
| **異常流程** | 1. 若系統中無任何頁面資料，列表區顯示「查無資料」。 |
| **特殊規則** | 1. 本頁不提供搜尋與篩選條件，一律顯示全部資料。<br>2. 後台已執行硬刪除之頁面不得出現於本列表。<br>3. 免登入瀏覽與後台入口隔離依 `NFR-003`。 |
| **參考資料** | 無 |

### 介面欄位定義

*   **搜尋欄位定義**：本頁不提供搜尋條件。
*   **預設排序定義**：建立日期（由新至舊）；同一建立日期時，以主鍵由大至小為次要排序（主鍵定義見 `[PAG-ADM-FN-002]` 欄位定義表，系統自動遞增，數值大者為較晚建立之資料）。本排序同時作為 `[PUB-WEB-FN-002] 前台 頁面內容顯示` 上下則導覽之基準。
*   **列表顯示定義**：
    | 欄位名稱 | 輸入控制 | 資料類型 | 資料長度 | 預設值 | 提示文字 | 說明 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 序號 | 唯讀 | 文字顯示 | - | - | - | 1. 依當前排序之流水號。 |
    | 頁面名稱 | 唯讀 | 連結 | - | - | - | 1. 文字超連結，點擊導向前台頁面內容顯示。<br>2. 開啟方式：本頁。 |
    | 建立日期 | 唯讀 | 文字顯示 | - | - | - | 1. 格式 YYYY-MM-DD。 |
*   **分頁功能定義**：每頁筆數可切換 10／20／50（預設 10）；顯示總筆數；提供跳頁輸入框與前後翻頁按鈕。

### 按鈕與動作
*   **頁面名稱（連結）**：點擊導向至 `[PUB-WEB-FN-002] 前台 頁面內容顯示`，並隨附主鍵資訊。

## 3. 驗收條件

### 正常情境（預期成功）

*   **AC-P1：依建立日期由新至舊顯示**
    *   **Given**: 系統中存在建立日期為 2026-01-10、2026-02-15、2026-03-20 之頁面資料各一筆。
    *   **When**: 瀏覽者開啟前台頁面列表。
    *   **Then**: 系統應依 2026-03-20、2026-02-15、2026-01-10 之順序由上而下顯示三筆資料。
*   **AC-P2：點擊頁面名稱導向內容頁**
    *   **Given**: 前台頁面列表中存在頁面「品牌故事」。
    *   **When**: 瀏覽者點擊「品牌故事」。
    *   **Then**: 系統應導向前台頁面內容顯示，且畫面標題為「品牌故事」。
*   **AC-P3：無資料時顯示查無資料**
    *   **Given**: 系統中不存在任何頁面資料。
    *   **When**: 瀏覽者開啟前台頁面列表。
    *   **Then**: 系統應於列表區觸發對應之查無資料提示（文案見商業邏輯表異常流程 1），總筆數顯示為 0。

### 阻擋情境（預期擋下）

*   **AC-B1：已刪除頁面不得出現於前台**
    *   **Given**: 後台管理人員已於 `[PAG-ADM-FN-001] 後台 頁面列表` 對頁面「測試頁面 A」完成刪除。
    *   **When**: 瀏覽者重新載入前台頁面列表。
    *   **Then**: 列表中不得出現「測試頁面 A」，總筆數應同步減 1。
