# [PUB-WEB-FN-002] 前台 頁面內容顯示

## 1. 商業邏輯

| 項目 | 定義 |
| :--- | :--- |
| **需求描述** | 身為 前台瀏覽者，我想要 依後台設定的版型閱讀該頁面的圖文內容，以便於 取得完整的頁面資訊。 |
| **使用對象** | 前台瀏覽者 |
| **前提條件** | 目標頁面資料存在於系統中。本頁不需登入即可瀏覽。 |
| **基本流程** | 1. 瀏覽者於前台頁面列表點擊某筆頁面名稱進入本畫面。<br>2. 系統依主鍵讀取該筆資料。<br>3. 系統依原儲存順序由上而下渲染全部圖文區塊，每一組各自依其「區塊版型」決定圖片與文字之排列方向。<br>4. 系統將「頁面內容」以 HTML 原樣渲染，並顯示補充說明。<br>5. 系統依排序基準判定本筆之相鄰資料，於頁尾顯示「上一則」與「下一則」導覽。<br>6. 瀏覽者點擊「上一則」或「下一則」，系統以相鄰該筆之主鍵重新載入本畫面。<br>7. 瀏覽者點擊「返回列表」，系統導回 `[PUB-WEB-FN-001] 前台 前台頁面列表`。 |
| **異常流程** | 1. 若目標頁面不存在或已被後台刪除，系統導回前台頁面列表並提示「資料不存在或已被刪除」。 |
| **特殊規則** | 1. 各組圖文區塊之排列方向完全由該組之「區塊版型」決定，組間互不影響，前台不提供切換。<br>2. 圖文區塊組數為 1～3 組，依後台儲存順序由上而下呈現。<br>3. 上下則之排序基準與 `[PUB-WEB-FN-001] 前台 前台頁面列表` 之〈預設排序定義〉完全一致；於該排序中位於本筆之前者為「上一則」，位於本筆之後者為「下一則」。<br>4. 本筆為排序中第一筆時不顯示「上一則」；為最後一筆時不顯示「下一則」；全站僅一筆資料時兩者皆不顯示。不顯示採整個元件隱藏，不以停用狀態呈現。<br>5. 上下則之計算範圍為全部頁面資料，不受進入本頁前之列表分頁位置影響。<br>6. 免登入瀏覽與後台入口隔離依 `NFR-006`。 |
| **參考資料** | 無 |

### 介面欄位定義

*   **A. 頁面資訊**：
    | 欄位名稱 | 輸入控制 | 資料類型 | 資料長度 | 預設值 | 提示文字 | 說明 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 頁面名稱 | 唯讀 | 文字顯示 | - | - | - | 1. 以頁面主標題呈現。 |
    | 建立日期 | 唯讀 | 文字顯示 | - | - | - | 1. 格式 YYYY-MM-DD。 |
*   **B. 圖文區塊（可重複群組，1～3 組）**：

    > 本群組依後台儲存順序由上而下重複呈現，下列欄位於每一組內各自存在一份。

    | 欄位名稱 | 輸入控制 | 資料類型 | 資料長度 | 預設值 | 提示文字 | 說明 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 區塊圖片 | 唯讀 | 圖片顯示 | - | - | - | 1. 顯示後台於該組上傳之圖片。<br>2. 該組區塊版型為「左圖右文」時圖片置於該組左側；為「右圖左文」時圖片置於該組右側。 |
    | 圖說文字 | 唯讀 | 文字顯示 | - | - | - | 1. 顯示於該組圖片之相對側，與區塊圖片同列。<br>2. 無資料時該側留空，不顯示替代文字。 |
*   **C. 內容區塊**：
    | 欄位名稱 | 輸入控制 | 資料類型 | 資料長度 | 預設值 | 提示文字 | 說明 |
    | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
    | 頁面內容 | 唯讀 | 文字顯示 | - | - | - | 1. 以後台儲存之 HTML 原樣渲染，保留粗體、斜體、項目清單、超連結與內嵌圖片。<br>2. 無資料時整區塊不顯示。 |
    | 補充說明 | 唯讀 | 文字顯示 | - | - | - | 1. 純文字顯示，保留原輸入之換行。<br>2. 無資料時整區塊不顯示。 |

### 按鈕與動作
*   **上一則**：顯示於頁尾左側，顯示文字為相鄰前一筆之頁面名稱。點擊以該筆主鍵重新載入本畫面。本筆為排序中第一筆時整個元件不顯示。
*   **下一則**：顯示於頁尾右側，顯示文字為相鄰後一筆之頁面名稱。點擊以該筆主鍵重新載入本畫面。本筆為排序中最後一筆時整個元件不顯示。
*   **返回列表**：點擊導向回 `[PUB-WEB-FN-001] 前台 前台頁面列表`。

## 3. 驗收條件

### 正常情境（預期成功）

*   **AC-P1：左圖右文版型正確呈現**
    *   **Given**: 系統中存在頁面「品牌故事」，其僅有 1 組圖文區塊，區塊版型為「左圖右文」，且已上傳區塊圖片與圖說文字。
    *   **When**: 瀏覽者開啟該頁面之內容顯示畫面。
    *   **Then**: 該組圖文區塊應以圖片在左、圖說文字在右之方式並列呈現。
*   **AC-P2：右圖左文版型正確呈現**
    *   **Given**: 系統中存在頁面「服務據點」，其僅有 1 組圖文區塊，區塊版型為「右圖左文」，且已上傳區塊圖片與圖說文字。
    *   **When**: 瀏覽者開啟該頁面之內容顯示畫面。
    *   **Then**: 該組圖文區塊應以圖片在右、圖說文字在左之方式並列呈現。
*   **AC-P3：多組圖文區塊依序呈現且版型各自獨立**
    *   **Given**: 系統中存在頁面「產品介紹」，其儲存有 3 組圖文區塊，版型依序為「左圖右文」、「右圖左文」、「左圖右文」，圖說文字依序為「甲」、「乙」、「丙」。
    *   **When**: 瀏覽者開啟該頁面之內容顯示畫面。
    *   **Then**: 畫面應由上而下呈現三組圖文區塊，圖說文字順序為「甲」、「乙」、「丙」，且第 1、3 組圖片置左、第 2 組圖片置右。
*   **AC-P4：頁面內容以 HTML 原樣渲染**
    *   **Given**: 後台已於「品牌故事」之頁面內容輸入含粗體文字與項目清單之內容。
    *   **When**: 瀏覽者開啟該頁面之內容顯示畫面。
    *   **Then**: 內容區塊應呈現粗體樣式與項目清單結構，不得顯示 HTML 標籤原始碼。
*   **AC-P5：中間篇同時顯示上一則與下一則**
    *   **Given**: 系統中僅存在三筆頁面，依排序基準由前至後為「甲頁面」、「乙頁面」、「丙頁面」。
    *   **When**: 瀏覽者開啟「乙頁面」之內容顯示畫面。
    *   **Then**: 頁尾應同時顯示「上一則」與「下一則」，其顯示文字分別為「甲頁面」與「丙頁面」。
*   **AC-P6：第一篇不顯示上一則**
    *   **Given**: 系統中僅存在三筆頁面，依排序基準由前至後為「甲頁面」、「乙頁面」、「丙頁面」。
    *   **When**: 瀏覽者開啟「甲頁面」之內容顯示畫面。
    *   **Then**: 頁尾不得出現「上一則」元件，「下一則」應顯示且其文字為「乙頁面」。
*   **AC-P7：最後一篇不顯示下一則**
    *   **Given**: 系統中僅存在三筆頁面，依排序基準由前至後為「甲頁面」、「乙頁面」、「丙頁面」。
    *   **When**: 瀏覽者開啟「丙頁面」之內容顯示畫面。
    *   **Then**: 頁尾不得出現「下一則」元件，「上一則」應顯示且其文字為「乙頁面」。
*   **AC-P8：僅一筆資料時上下則皆不顯示**
    *   **Given**: 系統中僅存在一筆頁面「甲頁面」。
    *   **When**: 瀏覽者開啟「甲頁面」之內容顯示畫面。
    *   **Then**: 頁尾不得出現「上一則」與「下一則」任一元件，僅顯示「返回列表」。
*   **AC-P9：點擊下一則正確切換內容**
    *   **Given**: 瀏覽者位於「甲頁面」之內容顯示畫面，「下一則」顯示文字為「乙頁面」。
    *   **When**: 瀏覽者點擊「下一則」。
    *   **Then**: 系統應載入「乙頁面」之內容，頁面主標題變更為「乙頁面」，且頁尾「上一則」顯示文字變更為「甲頁面」。
*   **AC-P10：選填欄位無資料時整區塊不顯示**
    *   **Given**: 系統中存在頁面「最新消息」，其頁面內容與補充說明皆為空值。
    *   **When**: 瀏覽者開啟該頁面之內容顯示畫面。
    *   **Then**: 畫面應僅呈現頁面資訊與圖文區塊，內容區塊整段不顯示，且不出現空白框線或替代文字。

### 阻擋情境（預期擋下）

*   **AC-B1：存取已刪除之頁面**
    *   **Given**: 瀏覽者已開啟頁面「測試頁面 A」之內容顯示畫面，後台隨後對該筆完成刪除。
    *   **When**: 瀏覽者重新載入該頁面。
    *   **Then**: 系統應觸發對應之異常提示（文案見商業邏輯表異常流程 1），並導回前台頁面列表，不得顯示任何殘留內容。
