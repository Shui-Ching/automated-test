# [AUT-ADM-FN-001] 後台 後台登入

## 1. 商業邏輯

| 項目 | 定義 |
| :--- | :--- |
| **需求描述** | 身為 後台管理人員，我想要 以固定帳號密碼登入後台，以便於 進入頁面管理功能維護前台內容。 |
| **使用對象** | 後台管理人員 |
| **前提條件** | 系統已內建可用之後台管理帳號。 |
| **基本流程** | 1. 使用者開啟後台登入頁。<br>2. 使用者輸入帳號與密碼。<br>3. 使用者點擊「登入」。<br>4. 系統驗證帳號與密碼是否與系統內建值一致。<br>5. 驗證通過，系統建立登入狀態並導向 `[PAG-ADM-FN-001] 後台 頁面列表`。 |
| **異常流程** | 1. 若帳號或密碼與系統內建值不一致，阻擋登入並於表單上方顯示紅字提示「帳號或密碼錯誤」，密碼欄位清空、帳號欄位保留輸入值。 |
| **特殊規則** | 1. 本系統僅提供單一內建帳號，帳號 `Admin`、密碼 `Admin1234`。<br>2. 不提供註冊、忘記密碼、變更密碼與帳號鎖定機制。<br>3. 錯誤提示不區分「帳號不存在」與「密碼錯誤」，一律回覆同一文案。<br>4. 後台頁面之存取權限阻斷依 `NFR-001`。<br>5. 登入狀態之逾時規則依 `NFR-002`。 |
| **參考資料** | 無 |

### 按鈕與動作
*   **登入**：觸發帳號密碼驗證。通過後建立登入狀態並導向 `[PAG-ADM-FN-001] 後台 頁面列表`；未通過依商業邏輯表異常流程處理，停留於本頁。
*   **通用行為**：驗證處理期間「登入」按鈕停用，防重複送出。

## 3. 驗收條件

### 正常情境（預期成功）

*   **AC-P1：成功登入後台**
    *   **Given**: 使用者位於後台登入頁，尚未建立登入狀態。
    *   **When**: 使用者輸入帳號「Admin」、密碼「Admin1234」並點擊「登入」。
    *   **Then**: 系統應建立登入狀態，並將頁面導向至「頁面列表」，畫面上可見「頁面管理」功能入口。

### 阻擋情境（預期擋下）

*   **AC-B1：欄位驗證（概括）**
    *   **Given**: 使用者位於後台登入頁。
    *   **When**: 任一欄位不符〈欄位驗證〉表所定義之規則，使用者點擊「登入」。
    *   **Then**: 系統應阻擋送出，並於對應欄位觸發該規則之錯誤提示（規則與文案見〈欄位驗證〉表，此處不重列）。
*   **AC-B2：帳號或密碼錯誤**
    *   **Given**: 使用者位於後台登入頁。
    *   **When**: 使用者輸入帳號「Admin」、密碼「Admin0000」並點擊「登入」。
    *   **Then**: 系統應阻擋登入，觸發對應之異常提示（文案見商業邏輯表異常流程），停留於登入頁，密碼欄位清空且帳號欄位保留輸入值。
