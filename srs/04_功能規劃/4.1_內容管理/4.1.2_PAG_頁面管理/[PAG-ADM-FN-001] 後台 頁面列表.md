# [PAG-ADM-FN-001] 後台 頁面列表

## 1. 商業邏輯

| 項目 | 定義 |
| :--- | :--- |
| **需求描述** | 身為 後台管理人員，我想要 檢索所有前台頁面資料並提供刪除機制，以便於 集中維護前台可瀏覽的內容。 |
| **使用對象** | 後台管理人員 |
| **前提條件** | 使用者已完成後台登入並具備登入狀態。 |
| **基本流程** | 1. 使用者點擊「頁面管理」進入頁面列表。<br>2. 系統讀取頁面資料並依預設排序顯示於畫面。<br>3. 使用者輸入篩選條件後點擊「查詢」，系統依條件重新載入列表。<br>4. 使用者點擊「清除」，系統清空所有篩選條件並重新載入全部資料。<br>5. 使用者點擊「新增」，系統導向 `[PAG-ADM-FN-002] 後台 新增頁面`。<br>6. 使用者點擊資料列上的「編輯」，系統導向 `[PAG-ADM-FN-003] 後台 編輯頁面`。<br>7. 使用者點擊資料列上的「刪除」，系統跳出二次確認彈窗。<br>8. 使用者於彈窗點擊「確認」，系統執行硬刪除、反饋成功訊息並重整列表。<br>9. 使用者點擊「登出」，系統結束登入狀態並導回 `[AUT-ADM-FN-001] 後台 後台登入`。 |
| **異常流程** | 1. 若篩選後無符合條件之資料，列表區顯示「查無資料」，分頁區顯示總筆數 0。<br>2. 若建立日期之起始日晚於結束日，阻擋查詢並於該欄位下方提示「結束時間不可早於開始時間」。 |
| **特殊規則** | 1. 刪除採硬刪除（Hard-delete），資料自資料表實體移除，不可復原且不保留操作軌跡。<br>2. 頁面資料一經刪除，前台立即不可瀏覽。<br>3. 本頁之存取權限阻斷依 `NFR-004`；登入逾時處理依 `NFR-005`。 |
| **參考資料** | 無 |

*   **分頁功能定義**：每頁筆數可切換 10／20／50（預設 10）；顯示總筆數；提供跳頁輸入框與前後翻頁按鈕。

### 刪除確認彈窗

| 元件 | 定義 |
| :--- | :--- |
| 彈窗標題 | 刪除確認 |
| 內文 | 確定要刪除此筆頁面資料嗎？刪除後將無法復原。 |
| 確認 | 執行硬刪除，關閉彈窗、顯示成功提示「刪除成功」並重整列表。 |
| 取消 | 關閉彈窗，不執行任何資料異動，列表維持原狀。 |

### 按鈕與動作
*   **查詢**：依搜尋區條件重新載入列表，並將分頁重置回第 1 頁。
*   **清除**：清空所有搜尋條件並重新載入全部資料。
*   **新增**：點擊導向至 `[PAG-ADM-FN-002] 後台 新增頁面`。
*   **編輯**：點擊導向至 `[PAG-ADM-FN-003] 後台 編輯頁面`，並隨附主鍵資訊。
*   **刪除**：點擊後跳出「刪除確認彈窗」，確認後執行硬刪除，Toast 提示文案為「刪除成功」，執行完畢後重整列表。
*   **登出**：結束登入狀態並導向 `[AUT-ADM-FN-001] 後台 後台登入`，Toast 提示文案為「已登出」。
*   **通用行為**：所有送出型按鈕於處理期間停用，防重複送出。

## 3. 驗收條件

### 正常情境（預期成功）

*   **AC-P1：依頁面名稱關鍵字篩選**
    *   **Given**: 列表中存在頁面名稱「關於我們」與「聯絡我們」。
    *   **When**: 使用者於「頁面名稱」輸入「關於」並點擊「查詢」。
    *   **Then**: 系統應僅顯示「關於我們」一筆，分頁區總筆數顯示為 1。
*   **AC-P2：依建立日期區間篩選**
    *   **Given**: 列表中存在建立日期為 2026-01-10 與 2026-03-20 之頁面資料各一筆。
    *   **When**: 使用者將建立日期設為 2026-01-01 ~ 2026-01-31 並點擊「查詢」。
    *   **Then**: 系統應僅顯示建立日期 2026-01-10 之該筆資料。
*   **AC-P3：成功刪除頁面（硬刪除）**
    *   **Given**: 使用者位於頁面列表，且列表中存在頁面「測試頁面 A」。
    *   **When**: 使用者點擊該筆之「刪除」，並於刪除確認彈窗中點擊「確認」。
    *   **Then**: 系統應實體移除該筆資料、顯示成功提示（文案見〈按鈕與動作〉）並重整列表，重整後列表不再出現「測試頁面 A」，總筆數減 1。
*   **AC-P4：取消刪除**
    *   **Given**: 使用者已於頁面列表點擊某筆資料之「刪除」，刪除確認彈窗已開啟。
    *   **When**: 使用者點擊「取消」。
    *   **Then**: 系統應關閉彈窗且不執行任何資料異動，該筆資料仍存在於列表，總筆數不變。
*   **AC-P5：篩選結果查無資料**
    *   **Given**: 列表中不存在頁面名稱含「XYZ」之資料。
    *   **When**: 使用者於「頁面名稱」輸入「XYZ」並點擊「查詢」。
    *   **Then**: 系統應於列表區觸發對應之查無資料提示（文案見商業邏輯表異常流程 1），總筆數顯示為 0。

### 阻擋情境（預期擋下）

*   **AC-B1：建立日期起始晚於結束**
    *   **Given**: 使用者位於頁面列表。
    *   **When**: 使用者將建立日期設為 2026-03-31 ~ 2026-03-01 並點擊「查詢」。
    *   **Then**: 系統應阻擋查詢，觸發對應之異常提示（文案見商業邏輯表異常流程 2），列表內容維持查詢前狀態。

### 例外情境（系統異常）

> 本區為系統層行為，不納入 AC 編號池，不列入客戶驗收範圍。

*   **EX-1：同一筆資料被重複刪除**
    *   **Given**: 同一帳號於兩個瀏覽器分頁開啟頁面列表，兩邊畫面皆存在頁面「測試頁面 A」。
    *   **When**: 於分頁 A 完成刪除後，於未重整的分頁 B 對同一筆點擊「刪除」並確認。
    *   **Then**: 系統不得重複執行刪除或寫入錯誤軌跡，應提示該筆資料已異動並重整列表。
